# Stokes constants through homotopy

Animations accompanying the paper *Stokes Constants through Homotopy* (Aniceto, Feldbrugge and Howls).

See the page https://jfeldbrugge.github.io/Stokes-Constants-through-Homotopy/

Build the page with `make` (pandoc). The animations are generated by `animate.jl` in the paper's
`Calculations/Homotopy figures` folder.
